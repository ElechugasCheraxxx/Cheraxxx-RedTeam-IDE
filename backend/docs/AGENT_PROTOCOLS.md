# Agent Communication Protocols

## Message Schema

Every message carries: msg_id, timestamp, from_agent, to, channel, type, priority, payload.

## Message Types

| Type        | Direction              | Use                                      |
|-------------|------------------------|------------------------------------------|
| BRIEFING    | Cipher → Orchestrators | Operation start, objective distribution  |
| TASK        | Orchestrator → Agent   | Assign specific work                     |
| FINDING     | Agent → Orchestrator   | Report discovered intelligence           |
| REQUEST     | Any → Any              | Ask for information                      |
| RESPONSE    | Any → Any              | Answer a REQUEST                         |
| SITREP      | Agent → Orchestrator   | Periodic status update                   |
| ESCALATE    | Any → Cipher/Operator  | Requires higher-level decision           |
| PIVOT       | Cipher/Orch → Team     | Change of vector/focus                   |
| INJECT      | Operator → Any         | Human intervention                       |
| ACKNOWLEDGE | Any → Any              | Confirm receipt of requires_ack message  |

## Channel Map

```
#general          — Cipher broadcasts to all
#cipher-rex       — Cipher ↔ Rex
#cipher-atlas     — Cipher ↔ Atlas
#cipher-vector    — Cipher ↔ Vector
#rex-atlas        — Rex ↔ Atlas peer
#rex-vector       — Rex ↔ Vector peer
#atlas-vector     — Atlas ↔ Vector peer
#rex-agents       — Rex ↔ Wraith/Spectre
#atlas-agents     — Atlas ↔ Ghost/Mirage
#vector-agents    — Vector ↔ Archive/Echo
#escalations      — Escalation bus
#operator         — Human operator
```

## Headless Constitution

Generated by Cipher at BRIEFING phase. Stored in SQLite.
Contains: objective, scope, restrictions, sub_objectives, phase_priorities, escalation_rules.
Used by Rex/Atlas/Vector when Cipher is offline (Headless Mode).
